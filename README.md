# Sandra Gumoshabe - Personal Portfolio

A modern, responsive personal portfolio website designed for **Sandra Gumoshabe**, a Junior Developer & Computer Science Student at Women's Institute of Technology and Innovation.

## ✨ Features

- **Hero & Intro**: Personal introduction, credential badge, and quick actions (resume download & get in touch).
- **About Me & Aspirations**: Dual card layout highlighting problem-solving approach and professional aspirations.
- **Skills & Expertise**: 2×2 dark card grid categorizing Web Development, Backend & Databases, Data Science & Machine Learning, and Design Tools.
- **Featured Work**: Project cards for full-stack and data science projects, including an interactive Random Forest model validation widget.
- **Direct Connect**: Interactive contact section featuring a speech bubble, click-to-copy email/phone pills, and direct messaging form with topic exploration chips.
- **Responsive Navigation**: Glassmorphic floating navbar with smooth scroll spy and mobile navigation drawer.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vite.dev/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Styling**: Vanilla CSS with custom design tokens, modern typography (`Plus Jakarta Sans`), and micro-interactions

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/gumosh1sandra/portfolio-assignment.git
   cd portfolio-assignment
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173` (or the port specified in terminal).

### Production Build

```bash
npm run build
npm run preview
```
